# 2026-10-23: the name is Sky Monitor

Chosen over Bahasa candidates (Dari Langit, Langit Kita, Udara Kita) because
the owner wanted an English name that covers smoke, rain, wind and whatever
a satellite sees next. "Monitor" says what it does; "Sky" says where the
data comes from. Neither word is an agency name, an alert-level word or
"official".

Rejected: Skynet (someone else's trademark several times over, surveillance
connotation, every namespace taken), Doomsday Monitor (a warning before a
single number loads; no agency would partner with it).

Checked 2026-10-23 by whois and the GitHub API: skymonitor.id and
skymonitor.org unregistered; GitHub user and organisation `skymonitor` free.
Not checked: Instagram handle, DJKI trademark register (blocks automated
access). Those are hand checks for the owner before registering.

Working namespaces until the owner registers: folder `~/projects/skymonitor`,
private GitHub repo `skymonitor` under the owner's account, to be transferred
to an organisation of the same name at launch.
