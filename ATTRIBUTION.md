# Attribution

Required notices for every source the project uses, verbatim where the
source prescribes wording. Each must appear wherever that source's data is
shown, and in the metadata of every published data file that derives from
it.

## NASA FIRMS (active fire detections)

"We acknowledge the use of data and/or imagery from NASA's Fire Information
for Resource Management System (FIRMS) (https://earthdata.nasa.gov/firms),
part of NASA's Earth Science Data and Information System (ESDIS)."

Data: public domain (CC0). Satellites: VIIRS on NOAA-20 and NOAA-21.

## NASA GIBS (satellite imagery tiles)

"We acknowledge the use of imagery provided by services from NASA's Global
Imagery Browse Services (GIBS), part of NASA's Earth Science Data and
Information System (ESDIS)."

Layers: Himawari-9 AHI (JMA), IMERG (GPM).

## Open-Meteo (weather model data)

Link next to any place the data is shown:
"Weather data by Open-Meteo.com" (https://open-meteo.com/), CC BY 4.0.
Models requested: JMA, GFS, ICON, ECMWF IFS. UK Met Office data is not
requested (its upstream licence is CC BY-SA).

## Permen LHK P.14/MENLHK/SETJEN/KUM.1/7/2020 (ISPU)

Breakpoints, categories, colours and the advice column are quoted from the
regulation and cited as "Permen LHK P.14/2020, Lampiran I/II".

## HDX / OCHA (administrative boundaries, if used)

"Indonesia - Subnational Administrative Boundaries", OCHA ROAP, source BPS,
CC BY-IGO. See `data/boundaries/SOURCE.md` for the boundary source in use.

## OpenStreetMap (if used for boundaries, landfill polygons or base map)

"(c) OpenStreetMap contributors", ODbL. Derived boundary files carry ODbL.

## OpenFreeMap (base map, if used)

OpenFreeMap, OpenMapTiles, OpenStreetMap contributors.

## Copernicus GLO-30 DEM (terrain, if used)

"(c) DLR e.V. 2010-2014 and (c) Airbus Defence and Space GmbH 2014-2018
provided under COPERNICUS by the European Union and ESA; all rights
reserved". If modified: "produced using Copernicus WorldDEM-30".

## BMKG and KLHK (once relayed)

"Sumber: BMKG" with product title, access time and direct link, shown whole
and unaltered (BMKG terms Pasal 9). KLHK ISPU readings cited as "Sumber:
KLHK ISPUnet" with station and time.
